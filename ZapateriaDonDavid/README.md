# Información
- Proyecto: Zapateria "Don David"
- Grupo: GTI174
- Descripcion:
El presente proyecto consiste en el desarrollo de una aplicación web (Punto de Venta y Gestión de Inventario) para una zapatería local especializada en botas vaqueras y calzado de trabajo. Surge de la necesidad de modernizar la tienda, la cual actualmente opera mediante registros manuales, lo que dificulta el control preciso de existencias y ralentiza el cálculo del total vendido al día. La solución tecnológica busca agilizar el registro de ventas en mostrador y mantener un control automatizado del inventario y de los ingresos diarios.
